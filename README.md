
# 🎵 Music Player

A responsive music player built using HTML, CSS, and JavaScript.

## ✨ Features

- ▶️ Play / Pause
- ⏭️ Next Song
- ⏮️ Previous Song
- 🔁 Repeat
- 🔀 Shuffle
- 🎵 3 Songs
- 🖼️ Song Cover Images
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
